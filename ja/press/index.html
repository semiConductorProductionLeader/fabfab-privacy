ゲーム紹介

ファブファブディフェンスは、鉱石と部品が動き出す半導体工場を舞台に、ふたりでリアルタイムに守る協力タワーディフェンスです。8の字マップを半分ずつ守り、両方の敵が通る真ん中の共有ルートで助け合います。

撃破報酬はふたりとも同じだけ獲得。ラストヒットの奪い合いはなく、協力だけが残ります。ランダムマッチで出会った仲間と、ルームコードで友だちと、ひとりでも始められます。

スロットで銅・シリコン・金などの元素の仲間を引き、レシピどおりに合成してトランジスタ → CPU → ゲーミングPCへ。ユニット34種、5段階のドット絵マスコットが登場します。

前作「スロット：半導体ディフェンス」の世界とユニットを受け継ぎ、個人開発スタジオ factoryjam が企画からサーバー運営までひとりで作りました。

特徴

  • ふたりで守るリアルタイム協力 — 8の字マップを分担して守り、真ん中の共有ルートで助け合おう。撃破報酬はふたりとも獲得！
  • スロットで引いて、レシピで育てる — 銅・シリコン・金を合成してトランジスタ → CPU → ゲーミングPCへ。ユニット34種、レシピ22種、5段階。
  • 全50ウェーブ、ボスを倒せ — 10・20・30・40・50ウェーブのボスを制限時間内に。1プレイ12〜15分、片手で遊べる縦画面。
  • 育てる楽しさ — ユニットを強化するとLv8で新スキルが解放。レジェンドはLv16で覚醒スキルも！
