About the game

FabFab Defense is a real-time co-op tower defense game for two, set in a semiconductor fab where ores and parts come to life. Players split a figure-8 map, each guarding a half, and help each other in the shared lane where enemies from both loops pass.

Every kill rewards both players equally, so there is no last-hit racing — only teamwork. Play with a random partner, invite a friend with a room code, or start solo.

Spin the slot to summon element buddies like Copper, Silicon and Gold, then combine them by recipe into a Transistor → CPU → Gaming PC. 34 pixel-art mascots across five grades.

Carrying on the world and units of the earlier Slot: Semiconductor Defense, it was made end to end — design to server operations — by factoryjam, a one-person studio.

Features

  • Real-time co-op for two — Split a figure-8 map, help each other in the shared lane — both players get every kill reward.
  • Spin, combine, grow — Combine Copper, Silicon and Gold into a Transistor → CPU → Gaming PC. 34 units, 22 recipes, five grades.
  • 50 waves, epic bosses — Beat the bosses on waves 10, 20, 30, 40 and 50 in time. 12–15 minute runs, one-handed portrait play.
  • Grow your roster — Level a unit to 8 to unlock a new skill — legendaries awaken a second one at level 16!
